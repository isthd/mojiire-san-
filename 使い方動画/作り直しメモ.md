# 使い方動画の作り直しメモ

使い方動画（`文字入れさん_使い方.mp4`）がアプリの今の画面とずれていないかを記録する。
アプリの「使い方動画」ボタンで流れるのはこの動画（`npm run build` のときに `public/videos/howto.mp4` へコピーされる）。

## ルール

1. **機能を追加・変更したら、動画の台本と照らし合わせる**
   - 台本は `制作スクリプト/narration.json`（見出し `caption`・読み上げ `say`・字幕 `subs`）。
   - 台本に出てくる画面・ボタンの名前・場所・手順が変わったら →「ずれている点」に書き足し、ユーザーに伝える。
   - 動画で紹介していない大きな新機能を追加したら →「紹介していない新機能」に書き足す（見た目の調整や不具合修正は書かなくてよい）。
   - お知らせ（`src/lib/news.ts`）を足すときに、あわせてこのメモも更新する。
2. **作り直しをユーザーに提案するタイミング**（作り直すかどうかはユーザーが決める）
   - 「ずれている点」に、基本の流れ（読み込み → 入力 → 保存）にかかわるものが1つでも入ったら → すぐ提案する。
   - 「紹介していない新機能」が3〜4個たまったら → 提案する。
3. **作り直すとき**
   - 毎回ゼロからではなく、場面ごとに見直す（ずれた場面を直し、新機能の場面を足す）。
   - 手順は `制作スクリプト/README.md`。できあがったら各場面の画面を確認する。
   - 動画は必ず **main に入れる**（ブランチに置いたままだとアプリに出ない）。main に push すると公開サイトにも自動で出る。
   - 作り直したら、下の「今の動画」を書きかえ、「ずれている点」「紹介していない新機能」を空にする。
