# 文字入れさん — 学習用画像エディター

学校のプリント・教科書・問題集の画像に、**テキスト・数式・手書き・直線／矢印・図形**を書き込み、元の解像度のまま画像やPDFとして保存できるWebアプリです。

- ログイン・登録不要、完全無料
- 編集内容はお使いの端末のブラウザ内にのみ保存
- ホーム画面に追加してアプリとして起動、オフラインでも動作
- Windows（Chrome / Edge）、iPad（Safari / Chrome）、スマートフォンに対応
- マウス・タッチ・Apple Pencil に対応

公開先：https://isthd.github.io/mojiire-san-/

---

## 使い方

1. ホームの「画像から新規作成」で写真や PDF を選ぶ（PDF は1ページずつ画像になります）
   - 写真がななめ・机が写り込んでいるときは、右上の「…」→「切り抜き・まっすぐにする」。紙のふちを自動で探して四隅に ● を置くので、ずれていたらドラッグで合わせて「完了」。左右の回転もここでできます（「元に戻す」で戻せます）
2. 下の **⊕** をタップ → 画面中央に「ダブルタップで入力」の枠が置かれるので、好きな位置へドラッグしてからダブルタップ → 入力画面で文字を入力（上部で「横書き／縦書き」を選択、「数式を入力」で数式も入れられる）→「完了」
   - 入力画面の右下に文字数が出ます。漢字に変換した語は、変換前に入力した読みの文字数で数えます（「じゃあく」→「邪悪」は4文字）。漢字の文字数と違うときは「（表記 2文字）」のように併記します
   - 左下の **回答欄** をタップすると、画像の中の空いた回答欄（罫線の枠・表の空きマス・下線）を探して、欄の大きさに合わせた「ダブルタップで入力」の枠をまとめて置きます（縦長の欄は縦書き、「答え」「(1)」などの見出しがある欄はその後ろから）。未入力の枠は書き出しには含まれません
3. 置いた文字はドラッグで移動、四隅の●で拡大・縮小。選択中は下部のアイコンで フォント／文字色／背景色／間隔／縁取り／回転 を変更、ゴミ箱で削除
4. 文字をダブルタップすると入力画面で再編集
5. 手書きや線・図形は左下の「描く・図形」から（終わったら「完了」）
6. 右上の「保存」で PNG / JPEG / PDF に書き出し

### フォルダとして保存（iCloud Drive・OneDrive）

プロジェクトの「…」→「フォルダとして保存」（編集画面では右上の「…」）で、画像と書き込みを入れたフォルダとして保存できます。

```
数学 p.12/
├── project.json   書き込みの内容
├── images/01.png  元の画像（画質そのまま）
├── thumbnail.jpg
└── README.txt
```

- **パソコン（Chrome / Edge）**：保存先に OneDrive や iCloud Drive の中のフォルダを選ぶと、そこへ直接保存されます。保存先は覚えておき、次からはボタン1つで保存（同じプロジェクトは上書き）できます
- **iPad / iPhone**：フォルダを ZIP にまとめ、「共有して保存」→「"ファイル"に保存」で iCloud Drive や OneDrive へ保存します。ファイルアプリで ZIP をタップするとフォルダに戻ります
- **読み込み**：ホームの「読み込む」から「フォルダを選ぶ」（パソコン）か「ファイルを選ぶ」（ZIP・バックアップ）。フォルダや ZIP はドラッグ＆ドロップでも読み込めます。iPad では、ファイルアプリでフォルダを長押し →「圧縮」してから ZIP を選びます
- アプリ内のフォルダごと保存すると、フォルダ分けもそのまま保存され、読み込むと同じ名前のフォルダに戻ります

### フォルダで整理

- ホームのフォルダボタン（すべて／未分類／各フォルダ）で表示を切り替え。フォルダを開いているときに作成・読み込みしたプロジェクトはそのフォルダに入ります
- 「…」→「フォルダへ移動」、または「選択」で複数選んで「移動」。パソコンではカードをフォルダボタンへドラッグしても移動できます
- **おまかせ整理**：未分類のプロジェクトを「名前が似ているもの」（「数学 p.12」「数学 p.13」→「数学」）や「作った月ごと」にまとめる候補を出し、選んだものをまとめてフォルダに入れます
- 名前で検索（すべてのフォルダから）、並び替え（更新順・作成順・名前順）
- フォルダの名前変更・削除（中のプロジェクトは消えずに未分類へ）

| 数式 | 記号入力（□をタップして値を入力）、記号パレット（8分類）、テンプレート約450種（中学〜高校数学・物理・化学・単位など16分野、よみ・カタカナでの検索、最近使ったもの）、LaTeX 直接入力、リアルタイムプレビュー、再編集、サイズ・色変更 |
| 手書き | ペン（太さ1〜30、色、不透明度、手ぶれ補正）、蛍光ペン（自由曲線／直線、乗算合成で下の文字が読める） |
| 図形 | 直線・矢印（一方向／双方向、先端サイズ、実線／破線／点線、端点ハンドル、水平・垂直への吸着、Shift で15°刻み）、四角形・円／楕円・三角形（枠線・塗り・透明度） |
| 編集 | 選択・移動・拡大縮小・回転、複数選択（Shift/Ctrl+クリック）、複製、コピー＆ペースト、削除、重なり順、元に戻す／やり直す（最大100件）、消しゴム（ストローク単位）、数値での位置・サイズ・回転指定 |

| 書き出し | PNG / JPEG（元画像と同じ解像度・2倍・3倍、画質指定）、全ページ一括、PDF（全ページを1ファイル・縦横比維持）、iPad では共有シートから「画像を保存」 |
| iPad 向け | ペン入力のみモード（指は画面移動・手のひら誤タッチ防止）、Pencil 描画中のタッチ無視、大きなタッチターゲット、UI拡大設定 |

### キーボードショートカット（Mac は Ctrl の代わりに Command）

| キー | 動作 |
| --- | --- |
| Ctrl+Z / Ctrl+Y・Ctrl+Shift+Z | 元に戻す / やり直す |
| Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D | コピー / 切り取り / 貼り付け / 複製 |
| Delete・Backspace / Esc | 削除 / 選択解除 |
| Ctrl+A / Ctrl+S | すべて選択 / 保存 |
| Ctrl+0 / Ctrl+1 / Ctrl+＋ / Ctrl+− | 画面に合わせる / 100% / 拡大 / 縮小 |
| 矢印キー（Shift で10px） | 選択中のオブジェクトを移動 |
| V T M P H L A R O G E | 選択 / テキスト / 数式 / ペン / 蛍光ペン / 直線 / 矢印 / 四角形 / 円 / 三角形 / 消しゴム |
| Space + ドラッグ | 画面の移動 |
| Ctrl+Enter / Esc（テキスト入力中） | 入力を確定 |

テキスト・数式の入力中はショートカットは無効になり、文字入力を妨げません。

### iPad でアプリとして使う

1. 上の URL を Safari で開く
2. 共有ボタン →「ホーム画面に追加」
3. 一度開けば以後はオフラインでも起動できます

## 注意事項

- データはブラウザごとに保存されます。ブラウザのサイトデータを削除すると消えるため、大切なプロジェクトはホーム画面の「…」→「バックアップを保存」で書き出してください。
- 文字数を読みで数えられるのは、この入力画面で変換した語だけです。貼り付けた漢字や、読みを最後まで入力する前に予測候補から選んだ漢字は、漢字の文字数（またはそこまでの読み）で数えます。
- PDF は各ページを画像（長い辺 約2500px）にして読み込みます。パスワード付きの PDF は読み込めません。
- iPad / iPhone では Canvas の上限（約1600万画素）があるため、非常に大きな画像を2〜3倍で書き出すと自動的に解像度を下げます（その旨を表示します）。
- フォント「丸ゴシック」「教科書体」「UDゴシック」「UD明朝」「手書き風」「マーカー風」「ポップ」「筆文字」「ペン字」「丸文字」「極太ゴシック」「ドット」「デコ明朝」は Google Fonts（Zen Maru Gothic / Klee One / BIZ UDPGothic / BIZ UDPMincho / Yomogi / Yusei Magic / Mochiy Pop One / Yuji Syuku / Zen Kurenaido / Hachi Maru Pop / Dela Gothic One / DotGothic16 / Kaisei Decol）を使用します。初回のみ通信が必要で、以後はキャッシュされます。
