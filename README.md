# 文字入れさん — 学習用画像エディター

学校のプリント・教科書・問題集の画像に、**テキスト・数式・手書き・直線／矢印・図形**を書き込み、元の解像度のまま画像やPDFとして保存できるWebアプリです。

- ログイン・登録不要、完全無料（サーバー不要の静的サイト）
- 編集内容は端末のブラウザ内（IndexedDB）にのみ保存
- PWA対応：ホーム画面に追加してアプリとして起動、オフラインでも動作
- Windows（Chrome / Edge）、iPad（Safari / Chrome）、スマートフォンに対応
- マウス・タッチ・Apple Pencil に対応

---

## 起動手順

必要なもの：Node.js 20 以上（開発時は 24 LTS で確認）

```bash
npm install
```

```bash
npm run dev
```

ブラウザで表示された URL（通常 http://localhost:5173）を開きます。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 型チェック＋本番ビルド（`dist/` に出力） |
| `npm run preview` | 本番ビルドをローカルで確認 |
| `npm run deploy` | GitHub へ push して GitHub Pages に公開 |
| `npm test` | ユニットテスト（Vitest） |
| `npm run typecheck` | 型チェックのみ |

> `npm install` 時に MathLive のフォントが `public/mathlive/fonts` にコピーされます（`scripts/copy-mathlive-assets.mjs`）。
> もし数式入力欄の記号が正しく表示されない場合は `node scripts/copy-mathlive-assets.mjs` を実行してください。

### iPad から開発中の画面を確認する

同じ Wi-Fi 内の iPad から確認する場合は `npm run dev -- --host` で起動し、表示された「Network」の URL を開きます。
（PWA のインストールとオフライン動作は HTTPS が必要なため、デプロイ後に確認してください。）

## デプロイ方法

ビルド結果（`dist/`）は静的ファイルだけなので、どの静的ホスティングでも公開できます。

### GitHub Pages（現在の公開先）

公開先：https://isthd.github.io/mojiire-san-/

```bash
npm run deploy
```

`main` ブランチで実行すると、次の3つをまとめて行います（`scripts/deploy.mjs`）。

1. 未コミットの変更があればコミットして GitHub へ push（メッセージは `npm run deploy -- "メッセージ"` で指定、省略時は `update`）
2. GitHub Pages 用のパス（`/mojiire-san-/`）でビルド
3. `dist/` を `gh-pages` ブランチへ公開

> このフォルダーは OneDrive 内にあるため、公開作業用のフォルダーは OS の一時フォルダーを使います。
> 公開直後は、ホーム画面に追加したアプリに古い版が残ることがあります。再読み込みするか、開き直すと新しい版になります。

### Vercel

1. GitHub にリポジトリを作成して push
2. Vercel で「Add New → Project」からリポジトリを選択
3. Framework Preset: **Vite** / Build Command: `npm run build` / Output Directory: `dist`
4. Deploy

### Netlify

1. 「Add new site → Import an existing project」からリポジトリを選択
2. Build command: `npm run build` / Publish directory: `dist`
3. Deploy

（手動の場合は `npm run build` 後、`dist` フォルダを Netlify の画面にドラッグ＆ドロップでも公開できます。）

### claude.ai の Artifact として公開する

```bash
npm run build:artifact
```

`dist-artifact/` に相対パス・Service Worker なしの版と、公開用ページ `artifact.html` が作られます。Artifact の枠内では通常のダウンロードができないため、保存は表示側の「downloads」機能（保存前に確認画面が出ます）を使います。Service Worker が使えないので、この版はオフライン動作・ホーム画面へのアプリ追加に対応しません。

### iPad でアプリとして使う

1. 公開した URL を Safari で開く
2. 共有ボタン →「ホーム画面に追加」
3. 一度開けば以後はオフラインでも起動できます

## 使い方

1. ホームの「画像から新規作成」で写真を選ぶ
2. 下の **⊕** をタップ → 画面中央に「ダブルタップで入力」の枠が置かれるので、好きな位置へドラッグしてからダブルタップ → 入力画面で文字を入力（上部で「横書き／縦書き」を選択、「数式を入力」で数式も入れられる）→「完了」
   - 入力画面の右下に文字数が出ます。漢字に変換した語は、変換前に入力した読みの文字数で数えます（「じゃあく」→「邪悪」は4文字）。漢字の文字数と違うときは「（表記 2文字）」のように併記します
   - 左下の **回答欄** をタップすると、画像の中の空いた回答欄（罫線の枠・表の空きマス・下線）を探して、欄の大きさに合わせた「ダブルタップで入力」の枠をまとめて置きます（縦長の欄は縦書き、「答え」「(1)」などの見出しがある欄はその後ろから）。未入力の枠は書き出しには含まれません
3. 置いた文字はドラッグで移動、四隅の●で拡大・縮小。選択中は下部のアイコンで フォント／文字色／背景色／間隔／縁取り／回転 を変更、ゴミ箱で削除
4. 文字をダブルタップすると入力画面で再編集
5. 手書きや線・図形は左下の「描く・図形」から（終わったら「完了」）
6. 右上の「保存」で PNG / JPEG / PDF に書き出し

## 技術スタック

| 分類 | 採用技術 |
| --- | --- |
| フロントエンド | React 19 + TypeScript |
| 開発環境 | Vite |
| スタイリング | Tailwind CSS v4 |
| アイコン | Lucide React |
| キャンバス | Konva + react-konva |
| 数式入力 | MathLive |
| 数式描画 | MathJax 3（`mathjax-full`、TeX → SVG） |
| 状態管理 | Zustand |
| ローカル保存 | IndexedDB + idb |
| PDF出力 | jsPDF |
| PWA | vite-plugin-pwa（Workbox） |

推奨スタックから変更した点：

- **バックアップ形式は「画像を含む単一 JSON ファイル」（`.mojiire.json`）** にしました。ZIP ライブラリを追加せずに済み、1ファイルで受け渡しでき、中身も確認しやすいためです。
- 数式は **入力に MathLive、表示・書き出しに MathJax** を使います。MathLive は入力のしやすさ（□をタップして入力）に優れ、MathJax の SVG はグリフをパスとして埋め込めるため、画像化しても欠けずに高解像度で出力できます。編集画面・プレビュー・書き出しはすべて同じ MathJax の描画結果を使うため、見た目が一致します。

設計上のポイント：

- **画像座標で一元管理**：すべてのオブジェクトは元画像のピクセル座標で保存し、ズーム・移動は表示時の変換（`lib/geometry.ts`）だけで扱います。拡大表示中でも正確な位置に書き込め、書き出しは元解像度のまま行えます。
- **表示と書き出しの一致**：`canvas/describe.ts` が「オブジェクト → 描画内容」を一か所で定義し、編集画面（react-konva）と書き出し（Konva 直接生成）の両方がそれを使います。
- **画像データは Blob で保存**：ページは画像の ID だけを持ち、巨大な Base64 文字列を状態や履歴に複製しません。履歴は不変データの構造共有なのでメモリ効率も良好です。
- **サイズの単位**：プロパティパネルのサイズは「ページの長辺＝1000」を基準とした単位で表示します。スマホ写真（高解像度）でもスキャン画像（低解像度）でも、同じ「文字サイズ24」が同じ見た目の大きさになります。
- **データ構造の拡張性**：オブジェクトはロック（`locked`）・グループ（`groupId`）を持てる型にしてあり、将来の機能追加に対応できます。

## 注意事項

- データはブラウザごとに保存されます。ブラウザのサイトデータを削除すると消えるため、大切なプロジェクトはホーム画面の「…」→「バックアップを保存」で書き出してください。
- 文字数を読みで数えられるのは、この入力画面で変換した語だけです。貼り付けた漢字や、読みを最後まで入力する前に予測候補から選んだ漢字は、漢字の文字数（またはそこまでの読み）で数えます。
- iPad / iPhone では Canvas の上限（約1600万画素）があるため、非常に大きな画像を2〜3倍で書き出すと自動的に解像度を下げます（その旨を表示します）。
- フォント「丸ゴシック」「教科書体」「UDゴシック」「UD明朝」「手書き風」「マーカー風」「ポップ」「筆文字」は Google Fonts（Zen Maru Gothic / Klee One / BIZ UDPGothic / BIZ UDPMincho / Yomogi / Yusei Magic / Mochiy Pop One / Yuji Syuku）を使用します。初回のみ通信が必要で、以後はキャッシュされます。
- このフォルダーは OneDrive 内にあるため、`node_modules`（数万ファイル）が同期対象になります。同期が重い場合はプロジェクトを OneDrive 外へ移動するか、`node_modules` を同期対象から除外してください。
